# 🍽️ FoodieHub

FoodieHub is a full-stack restaurant and menu management web application built with Node.js, Express, PostgreSQL, and EJS. Users can register, log in, and manage restaurants and menu items via a user-friendly dashboard.

![District Guessing Game Screenshot](./public/images/image.png)

---

## 🚀 Features

- 📝 User Registration & Login (with bcrypt password hashing)
- 📊 User Dashboard to view added restaurants
<!-- - ➕ Add, Edit, Delete restaurants and menu items -->
- 💡 EJS templating with clean responsive styling
<!-- - 🔐 Secure password storage with `bcrypt` -->

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Frontend:** EJS, CSS
- **Database:** PostgreSQL
